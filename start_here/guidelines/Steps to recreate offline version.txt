Steps to recreate offline version.

Hint: root password is stored on server on the following path:
/root/schule/secrets.env

1. install gibbon + offline data that comes with gibbon
2. Test if gibbon is working correctly.
3. Extract and package the db data from annur live server 
	a. cd schule
	b. docker exec gibbon_mysql mysqldump -u root -p'root_password' gibbon_DB > db_backup.sql 
	c. gzip db_backup.sql 
3. On your local machine: download and overwrite the existing data with the downloaded data using following commands.
	a. scp schule:/root/schule/db_backup.sql.gz .
	b. gunzip  db_backup.sql.gz
	c. docker exec -i gibbon_mysql mysql -u root -p'root_password' -e "DROP DATABASE gibbon_DB; CREATE DATABASE gibbon_DB"
	d. docker exec -i gibbon_mysql mysql -u root -p'root_password' gibbon_DB < db_backup.sql
	e. docker exec -i gibbon_mysql mysql -u root -p'root_password' gibbon_DB -e "UPDATE \`gibbonSetting\` SET value='http://localhost:8081' WHERE gibbonSettingID=1;" 
	f. docker exec -i gibbon_mysql mysql -u root -p'root_password' gibbon_DB -e "UPDATE \`gibbonSetting\` SET value='dummyEmailPass' WHERE name='mailerSMTPPassword'; UPDATE \`gibbonSetting\` SET value='purple' WHERE name='themeColour'; UPDATE \`gibbonSetting\` SET value='Development' WHERE name='installType';"
